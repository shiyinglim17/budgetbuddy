HOW TO PUSH THIS TO YOUR GITHUB REPO
=====================================

This folder is already a git repository. It has one commit and your
remote (https://github.com/shiyinglim17/budgetbuddy.git) is already set.
You just need to push it.

STEP 1 — Unzip this folder somewhere on your computer.

STEP 2 — Open a terminal inside the unzipped folder and run:

    git push -u origin main

GitHub will ask you to authenticate. Use either:
  - A Personal Access Token as the password
    (GitHub.com -> Settings -> Developer settings -> Personal access tokens),
  - or the GitHub CLI: run "gh auth login" first, then push.

That's it. Your repo is now on GitHub.

STEP 3 (optional, recommended) — Turn on free hosting:
  On GitHub: your repo -> Settings -> Pages -> Build and deployment
  -> Source -> select "GitHub Actions".
  The included workflow then builds and publishes the app automatically.
  Your tool will live at:
    https://shiyinglim17.github.io/budgetbuddy/

STEP 4 — To run it locally any time:
    npm install
    npm run dev

NOTE ON node_modules: this zip does NOT include the node_modules folder
(it's large and rebuildable). Running "npm install" recreates it. This is
normal and expected for any git repo.

See README.md for full details, including the Free vs AI Coach modes
and how to keep daily use at zero cost.
